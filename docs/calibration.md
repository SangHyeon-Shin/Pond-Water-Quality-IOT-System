# 센서 교정

교정하지 않은 센서의 값은 상태 비트에 `UNCALIBRATED`로 표시되고, 게이트웨이는 그 값으로 경보를 보내지 않습니다.
2024 현장 시험에서 맑은 수돗물이 탁도 약 146 NTU, 망고주스가 pH 6.3으로 나온 것도 교정이 없었기 때문입니다.

## 준비

1. 노드를 USB로 PC에 연결하고 시리얼 모니터를 **9600 baud**, 줄 끝 **Newline**(또는 Both NL & CR)으로 엽니다.
2. 시리얼 모니터를 열면 Uno가 리셋됩니다. **5초 안에 Enter**를 누르면 유지보수 모드로 들어갑니다.
3. 유지보수 모드에서는 3초마다 측정값과 **원시 전압**이 표시되고, **무선 송신과 슬립이 꺼집니다**.
   표준액에 담근 값이 대시보드에 기록되지 않습니다.
4. 모든 교정 명령은 그 자리에서 새로 측정한 값을 쓰고, 성공하면 **EEPROM에 저장**되어 재부팅 후에도 유지됩니다.
5. 끝나면 `exit`를 입력합니다.

**순서**: ① `cal vcc` → ② `cal temp` → ③ pH → ④ TDS → ⑤ 탁도 → ⑥ DO.
모든 전압 계산이 공급전압에 의존하므로 VCC를 가장 먼저 합니다.

## 명령

| 명령 | 용도 |
|---|---|
| `status` (`s`) | 지금 측정하고 원시 전압·교정값 표시 |
| `cal vcc <V>` | 멀티미터로 잰 5V 핀 전압 |
| `cal temp <°C>` | 기준 온도계 값 |
| `cal ph1 <pH>` / `cal ph2 <pH>` | 완충액 1·2 (예: `cal ph1 7.00`, `cal ph2 4.00`) |
| `cal tds <ppm>` | TDS 표준액 (예: `cal tds 707`) |
| `cal ntu0` | 증류수(0 NTU) |
| `cal ntu <NTU>` | 탁도 표준액 (예: `cal ntu 100`) |
| `cal do1` / `cal do2` | 공기 포화수 (2점은 온도가 5 °C 이상 다를 때) |
| `cal reset` | 기본값으로 되돌림 |
| `help`, `exit` | 도움말, 종료 |

값이 범위를 벗어나거나 두 점이 너무 가까우면 `REJECTED`가 출력되고 아무것도 바뀌지 않습니다.

## 1. 공급전압 — `cal vcc`

멀티미터로 Uno의 5V–GND 전압을 재고 입력합니다(예: `cal vcc 4.93`).
내부 1.1 V 기준(개체 편차 ±10 %)을 보정해 두면, 이후에는 측정할 때마다 실제 공급전압을 반영합니다.
하지 않으면 5.00 V로 가정합니다. 공급전압 3 % 오차는 V1 보드에서 pH 약 0.2의 오차가 됩니다.

## 2. 수온 — `cal temp` (선택)

DS18B20과 기준 온도계를 같은 물에 2분 이상 담근 뒤 기준 온도계 값을 입력합니다(±5 °C까지).
DS18B20의 공장 정확도는 ±0.5 °C(−10~85 °C, 데이터시트)이므로 기준 온도계가 없다면 생략해도 됩니다.

## 3. pH — 2점 교정

1. **보드 세대 확인**: pH 7 완충액에서 `status`의 pH 전압이 약 **2.0 V이면 V1**, 약 **1.5 V이면 V2** 보드입니다.
   `config.h`의 `PH_BOARD_VERSION`을 맞추면 교정 전 기본값이 정확해집니다. 교정 자체는 어느 쪽이든 동작합니다.
2. 전극을 증류수로 헹구고 물기를 가볍게 제거한 뒤 **pH 7.00** 완충액에 넣고, 전압이 안정되면(1~2분) `cal ph1 7.00`.
3. 다시 헹군 뒤 **pH 4.00** 완충액에 넣고 안정되면 `cal ph2 4.00`.
   알칼리성 연못이면 4.00 대신 10.01을 써도 됩니다(두 완충액은 1 pH 이상 차이).
4. pH 7 완충액에 다시 넣어 `status`가 7.00 ± 0.05인지 확인합니다.

한 점만 교정하면 기울기는 유지하고 오프셋만 보정합니다. 전극은 노화되므로 **매월** 다시 교정합니다.

## 4. TDS — k값

1. 표준액(예: **1413 µS/cm = 707 ppm**, 환산계수 0.5)에 TDS 프로브와 DS18B20을 함께 넣습니다.
2. 1~2분 뒤 `cal tds 707`. 온도 보정에 수온이 필요하므로 DS18B20이 정상이어야 합니다.
3. 계산된 k가 0.25~4.0을 벗어나면 거부됩니다(DFRobot GravityTDS와 같은 범위).

## 5. 탁도 — 2점 교정

1. 깨끗한 용기의 **증류수**(기포 없음, 그늘)에 센서를 넣고 `cal ntu0`.
2. **탁도 표준액**(포르마진 또는 시판 NTU 표준)에 넣고 표준값을 입력합니다. 예: `cal ntu 100`.
   표준액이 없으면 같은 시료를 상용 탁도계로 잰 값을 입력해도 됩니다.
3. SEN0189는 비선형이고 저탁도 분해능이 낮습니다. 연못에서 예상되는 범위(수~수십 NTU)에 가까운 표준을 쓰세요.

## 6. 용존산소 (선택, `ENABLE_DO_SENSOR 1`)

1. 물을 몇 분간 공기로 폭기해 포화시키거나, 프로브를 닫힌 용기 속 수면 위 습한 공기에 둡니다.
2. 안정되면 `cal do1`(현재 수온과 전압을 포화점으로 저장).
3. 수온이 5 °C 이상 다른 물에서 반복하면 `cal do2`로 2점 교정이 됩니다.

포화 용존산소는 Benson & Krause 식(담수, 1기압)으로 계산합니다(20 °C에서 9.09 mg/L).
갈바닉 프로브의 막과 전해액은 제조사 안내에 따라 관리합니다.
**DO 센서를 교정하기 전에는 폭기 제어가 DO를 무시하고 폭기를 계속 켜 둡니다.**

## 상태 비트 (Blynk V7, 시리얼 `status`)

| 비트 | 값 | 의미 |
|---|---|---|
| 0 | `0x0001` | 수온 무효(센서 없음·CRC 오류·범위 밖) |
| 1 | `0x0002` | pH 무효 |
| 2 | `0x0004` | 탁도 무효 |
| 3 | `0x0008` | TDS 무효 |
| 4 | `0x0010` | DO 무효(센서 미설치 포함) |
| 5~8 | `0x0020` `0x0040` `0x0080` `0x0100` | pH / 탁도 / TDS / DO 미교정 |
| 9 | `0x0200` | 공급전압 미교정(5.00 V 가정) |
| 10 | `0x0400` | 수온 무효로 TDS·DO를 25 °C로 보정 |
| 11 | `0x0800` | EEPROM에 교정값 없음(기본값 사용) |
| 12 | `0x1000` | 직전 패킷 전송 실패 |
| 13 | `0x2000` | 폭기 제어 사용 중 |

예: 교정 전 기본 상태는 `0x0AF0`(pH·탁도·TDS 미교정, VCC 미교정, DO 없음, 교정값 없음)입니다.
